# NF Photography — Website UI kit

A high-fidelity recreation of the NF Photography marketing website built directly from the brand guidelines. The site is a single-page editorial experience with discrete sections: hero, services, portfolio (sport-categorized), editorial about block, press strip, and a booking form.

## Files

- `index.html` — interactive click-thru of the full site (anchor nav, sport filter, booking form submit confirmation)
- `Header.jsx` — sticky nav with NF mark, sport links, Book CTA
- `Hero.jsx` — full-bleed hero with display tagline + supporting line
- `PortfolioGrid.jsx` — sport-filtered gallery grid using the brackets-overlay frame motif
- `EditorialBlock.jsx` — about / manifesto block (Pattern 02)
- `FeatureBlock.jsx` — navy section, white text (Pattern 03)
- `PressStrip.jsx` — press logo / quote strip
- `BookingForm.jsx` — match-day booking form with sport, club, date, contact
- `Footer.jsx` — dark footer with NF lockup
- `Buttons.jsx` — Primary / Secondary / Ghost button primitives

## Notes

The portfolio uses photographic placeholders (gradient-filled blocks with the corner-bracket overlay) — the live site would swap these for real Nicholas Falzon imagery. All copy in this kit follows the brand voice (sport-fluent, direct, no exclamations).
